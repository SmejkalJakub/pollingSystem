Priority issues:

1. [P1] One unsaved edit blocks unrelated work.
   Live verified: changing one juror name disabled Copy for all 14 saved jurors and the link XLSX export. Restoring the name re-enabled them.
   Fix: keep saved-link copying and saved-data export available; say “Export uses saved data; 1 row has unsaved changes.” New unsaved members still need saving first. Preserve authorization and revision checks.
   Evidence: apps/web/src/modules/admin/JurorTable.tsx:310 and :486.
   Suggested command: $impeccable shape.

2. [P1] Monitoring and operating a category happen in different places.
   Live verified: dashboard → category detail → management → Close → confirmation: four clicks before changing state, plus scrolling.
   Fix: put close/reopen beside the category status and unlock beside the relevant submitted juror. Keep context and offer an adjacent reverse action after close/reopen. Unlock can retain one clear consequence acknowledgement. The unlock path was source-reviewed; the fixture had no submitted ballots.
   Evidence: apps/web/src/modules/dashboard/CategoryDetail.tsx:147; apps/web/src/modules/admin/VotingDetail.tsx:151; apps/web/src/modules/admin/BallotUnlock.tsx:81.
   Suggested command: $impeccable shape.

3. [P2] Routine actions receive excessive ceremony.
   Close/reopen each opens another form. Spreadsheet import requires Preview → Add preview to table → Save after pasting. Discarding local edits requires another confirmation.
   Fix: direct reversible lifecycle actions with outcome feedback; import directly into an editable staged preview; local discard with Undo while the draft can still be restored. Keep saving explicit and distinguish it from submission.
   Evidence: apps/web/src/modules/admin/VotingDetail.tsx:151; apps/web/src/modules/admin/TeamPaste.tsx:58; apps/web/src/modules/admin/TeamTable.tsx:336.
   Suggested command: $impeccable distill.

4. [P2] The useful controls are too far from the work.
   Live verified: the first editable juror row starts below the initial desktop viewport. In a 21-team category, Save is about 3,400 pixels down the document. Each juror repeats Copy, Replace, Revoke and Remove controls.
   Fix: a compact persistent save bar, Copy as the obvious row action, exceptional actions in a secondary menu, and optional help instead of repeated instructions. Summarize frozen configuration on active categories.
   Evidence: apps/web/src/modules/admin/JurorControls.tsx:55; apps/web/src/modules/admin/VotingSetup.tsx; apps/web/src/modules/admin/VotingDetail.tsx.
   Suggested commands: $impeccable distill, $impeccable layout.

5. [P2] The juror footer asks users to manage too many separate steps.
   Source-reviewed: Save, Check, Submit, Previous and Next compete, with Review elsewhere. Check does not save; direct submission already saves and locks the current selection.
   Fix: one obvious “Save and continue” path; a clear separate submission action; validation-only Check as a secondary option or inline feedback. Preserve independent category submission and explicit locking.
   Evidence: apps/web/src/modules/voting-wizard/CategoryVoting.tsx:153; apps/web/src/modules/voting-wizard/DraftPersistence.tsx:181; apps/web/src/modules/voting-wizard/WizardContent.tsx:233.

Cognitive load: five of eight review checklist items fail: single focus, hierarchy, minimal choices, working-memory burden and progressive disclosure. D21 rules are intrinsic complexity; repeated explanations and navigation are avoidable complexity.

Persona red flags:

- Expert organizer: an unrelated name edit prevents copying a saved link; monitoring requires leaving the page to act.
- Keyboard user: repeated exceptional row actions create a long focus sequence; frequent confirmation/notice focus changes can interrupt context.
- First-time juror: Save, Check, Submit and Next require explanatory paragraphs to distinguish.

Emotional journey: calm entry → instruction-heavy preparation → frustration when unrelated controls disable → navigation during live operation → reassurance after clear save/submission feedback. Preserve the reassurance and remove the unnecessary valleys.
